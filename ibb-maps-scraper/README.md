# حاصر منشآت مدينة إب — المسح العميق القابل للاستئناف

هذا النظام يدمج عدة مصادر عامة، ويحفظ نقطة التقدم بعد كل دفعة حتى لا تضيع النتائج عند انتهاء مهلة GitHub Actions.

## طريقة العمل

- يبدأ تلقائيًا بعد دمج تحديثات إعداداته على `main`، ثم يُجدول دفعة جديدة كل 3 ساعات.
- كل تشغيل يعالج ما يصل إلى 8 خلايا مكانية، ويحفظ بياناتها وموضع الاستئناف في `deep_scan_state.json`.
- يستخدم مراحل شبكة `10×10` ثم `15×15` ثم `20×20` ثم `25×25` ثم `30×30`، ما لم يبلغ العدد الفريد 10,000 بعد إكمال مرحلة كاملة.
- يضم ملف الاستعلامات 75 صيغة عربية وإنجليزية تغطي قطاعات تجارية وخدمية وشوارع وأحياء ونقاطًا محلية.
- يحاول إضافة بيانات OpenStreetMap عبر Overpass عند توفرها، ثم يمسح مواقع الأعمال العامة التي تسمح قواعد `robots.txt` بفحصها لإثراء الهواتف والبريد والعنوان وساعات العمل وروابط الشبكات الاجتماعية وروابط الصور المنشورة.
- يجري اختبارًا آليًا محليًا قبل المسح في كل تشغيل، ثم يتحقق من تطابق عدد صفوف CSV وJSON قبل حفظ نقطة التقدم وقاعدة البيانات.

## الملفات الأساسية

- `ibb_city_complete_database.csv` و`ibb_city_complete_database.json`: قاعدة البيانات الموحدة.
- `scrape_report.json`: أعداد المصادر ونسب اكتمال الحقول وعدد السجلات.
- `deep_scan_state.json`: المرحلة الحالية والخلايا المكتملة وإعادات المحاولة والأخطاء والهدف.
- `deep_scan_tiles/`: مخرجات مؤقتة للخلايا الجارية؛ تزال بعد نجاح الدمج، وتبقى عند فشل الدمج حتى يمكن استعادتها.
- `ibb_skill1_results.csv` و`ibb_skill2_results.csv`: مخرجات المحركين.
- `ibb_osm_results.csv`: سجلات OpenStreetMap حيث توفرت.
- `website_enrichment_cache.json`: نتائج فحص المواقع العامة التي تمت زيارتها.
- `photo_urls`: روابط الصور المتاحة من الصورة المصغرة للقائمة، ووسوم الصور في OpenStreetMap، وصفحات الموقع العام. لا تُنزّل الصور ولا يُعاد استضافتها.

## حدود يجب معرفتها

- هدف 10,000 سجل هو شرط طموح للتقدم، وليس ضمانًا بأن المدينة تحتوي ذلك العدد أو أن محركات البحث ستكشفه كله. إذا انتهت كل الشبكات المخططة قبل بلوغ الهدف، يسجل التقرير `planned_grids_exhausted_target_not_reached` بدل الادعاء بالاكتمال.
- الشبكة ليست مسحًا حرفيًا كل 40 مترًا. محرك Google Maps المستخدم يفرض نصف قطر يقارب كيلومترًا أو أكثر لكل بحث؛ رفع عدد الخلايا يزيد فرص العثور على نتائج، لكنه لا يزيل حدود البحث أو النتائج المخفية.
- تُدمج السجلات باستخدام معرّف المكان والرابط والهاتف والعنوان والإحداثيات. لا توجد خوارزمية إزالة تكرار تضمن اكتشاف كل اختلاف إملائي دون احتمال دمج أعمال متشابهة خطأً؛ لذلك يبقى التدقيق البشري مهمًا.
- بيانات الصور روابط عامة فقط، ولا يعني وجود صورة مصغرة أنها تُظهر واجهة المبنى أو العنوان نفسه. لا يمكن ضمان صور Street View لكل منشأة دون مصدر متاح ومصرح به.
- لا يستخدم سير العمل تدوير البروكسيات لتجاوز الحظر. المواقع الخارجية لا تُفحص إلا إذا كانت عامة، ويُحترم `robots.txt`; قد تبقى الحقول فارغة إذا لم تنشرها المنشأة.
- المستودع `OAuth` عام؛ لذلك الملفات والنتائج الملتزم بها فيه قابلة للعرض العام. راجع شروط مصادر البيانات وحقوق إعادة الاستخدام قبل نشر قاعدة تجارية.

## التشغيل اليدوي

من GitHub: **Actions → Ibb Deep Resumable Census → Run workflow**. اترك `batch_size=8` للتشغيل المعتاد. نقطة التقدم محفوظة في المستودع، لذلك لا يبدأ من الصفر عند التشغيل التالي.
