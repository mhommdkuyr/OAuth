# حاصر منشآت مدينة إب

هذا المجلد يشغّل محركين مفتوحي المصدر بالتتابع ويجمع سجلاتهما في ملفات CSV وJSON مع إزالة التكرار.

## التشغيل

- عند إضافة/تحديث إعدادات المشروع على فرع `main`، يبدأ سير العمل تلقائياً.
- يمكن تشغيله يدوياً من **Actions → Ibb City Full Scraper (Dual Engine) → Run workflow**، مع `grid_size` من 1 إلى 10.
- ملفات الناتج: `ibb_city_complete_database.json` و`ibb_city_complete_database.csv`، مع تقرير `scrape_report.json`.
- ملفات المحركين الخام متاحة أيضاً في المستودع عند نجاح كل منهما.

## ما تم إصلاحه مقارنة بالمسودة الأولية

- تشغيل خدمة Docker API التي يحتاجها محرك Mahanaicoach قبل تشغيل سكربت Python.
- استخدام الخيار الصحيح `--out` بدلاً من `--output`.
- عدم الاعتماد على pandas أو حقل `name` غير الموجود في كل ملف CSV.
- توحيد أسماء الحقول وإزالة التكرار باستخدام معرّف المكان أو الرابط أو الاسم مع العنوان/الهاتف.
- حفظ قاعدة البيانات السابقة وإثراؤها في عمليات التشغيل التالية، وكتابة تقرير بعدد النتائج.

## حدود التغطية

هذا جمع آلي بأفضل جهد وليس ضماناً لحصر كل منشأة. قد تُحجب بعض النتائج أو تُفقد بسبب حدود نتائج البحث أو حدود الترميز الجغرافي أو تحديد المعدل أو تغيّر بيانات الأماكن. افحص السجلات المهمة من مصادرها العامة قبل الاعتماد عليها. لا يستخدم هذا الإعداد بروكسيات لتجاوز الحظر. راجع شروط المصدر قبل الاستخدام التجاري.
